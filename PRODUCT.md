## Product
Educational Master Center (EMC) — a multilingual education and volunteer operations platform for students, migrants, career changers, instructors, HR, and admins.

## Users & Purpose
- **HR / Admin**: review volunteer HR profiles, ambassador applications, team membership.
- **Students / Volunteers**: apply, learn, manage profiles.
- **Instructors**: run classes, materials, assessments.
Primary dashboard job: complete operational workflows quickly with clear Arabic RTL UI.

## Brand personality
Institutional, trustworthy, clear — deep navy (`#22334A`) + EMC blue (`#2691C2`) + warm accent (`#EC943C`).

## Anti-references
Generic purple SaaS dashboards, Bootstrap admin templates, dense spreadsheet UIs, dark neon tool aesthetics.

## Design principles
1. RTL-first Arabic UI with mixed Latin content preserved.
2. Use existing EMC tokens (deepBlue, customBlue, emcBg) — no new fonts or purple themes.
3. Prefer compact operational density over decorative marketing chrome in dashboards.
4. Preserve accessibility: dialogs, focus, keyboard actions, contrast.
5. Never invent data; empty states use «غير متوفر» only when needed.
