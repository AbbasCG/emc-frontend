## 2. القوانين الحاكمة (غير قابلة للنقاش)
- ⛔ **البرتقالي لا يُمزج أبداً مع عائلة البحر في تدرّج واحد** — البرتقالي يبقى صلباً.
- ⛔ **التدرّجات الزرقاء↔البرتقالية المباشرة ممنوعة** (الفجر = طبقات منفصلة: قاعدة عمق + توهّج سماوي + أفق برتقالي، وليس مزجاً خطّياً).
- ⛔ **السماوي والبرتقالي ليسا للنص الصغير على فاتح** — استخدم الكحلي / الأزرق `#0077B6` / الجمر `#C97208`.
- ⛔ **ممنوع اقتراح إعادة تصميم الشعار** (قرار المؤسس، يونيو 2026).
- ⛔ ممنوع: صناديق بحدود وظلال ثقيلة · أزرار مرسومة (الدعوة = نص برتقالي/جمر + «← ») · اكتظاظ بلا فراغ · إيموجي في التصاميم.

## 3. الطباعة
- **العناوين (display):** Tajawal — أوزان 500/700/800/900.
- **المتن (text):** IBM Plex Sans Arabic — 400/500/600/700 · اللاتيني: IBM Plex Sans.
- **احتياطي طوارئ فقط:** Cairo.
- الأرقام غربية 0-9 اتجاهها LTR داخل النص العربي؛ المصطلح اللاتيني يُعزل `dir="ltr"`.

## 4. التدرّجات
- **العمق (Depth):** `linear-gradient(135deg, #06182C, #0C2A4B 55%, #0E5A8A)` — فواصل وحقول البطل.
- **الفجر (Dawn):** قاعدة عمق + توهّج سماوي علوي + أفق برتقالي سفلي (طبقات radial منفصلة) — التوقيع المميّز للأغلفة.
- **الصحو (Daylight):** `linear-gradient(to left, #089FE0, #A6D6F2)` — المخططات والمؤشّرات على فاتح (عائلة البحر فقط).

## 5. الحركة
- **easing معتمد:** `cubic-bezier(0.2, 0.8, 0.2, 1)`.
- دخول عنوان 24px/0.85s · تتابع 0.12s · رسم قوس 0.6s · تلاشٍ متقاطع 0.7s · Ken-Burns ≤4%.
- **ممنوع:** bounce · elastic · flicker · طيران الشعار. الشعار يُختم به ساكناً ≥2s.
