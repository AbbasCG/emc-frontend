## 1) خط الإنتاج (Build)

| خطوة | الأمر | الشرط |
|------|-------|-------|
| تثبيت | `npm ci` | Node حسب `.nvmrc` / حقل `engines` |
| lint | `npx eslint . --quiet` | **0 أخطاء** |
| أنواع صارمة | `npm run typecheck:strict` | **0** (strict كامل على `src` منذ M7.B) |
| اختبارات | `npm test` | الكل أخضر (تشمل عتبات التغطية لكل مجلد في `vitest.config.ts`) |
| بناء | `npm run build` | ينتج `dist/` |
| سقّاطة الحزم | `npm run check:bundle` | أكبر chunk أولي < **250KB gz** |
| فحص تسريب | `npm run check:secrets` | نظيف (أسرار + `console.*` غير محروس) |
| E2E | `npx playwright test` | 28/28 (الرحلات + smoke، حاسوب + 375px) |
| أصول SEO | `npm run seo:assets` | sitemap/robots من `scripts/public-routes.mjs` عند تغيّر المسارات العامة |

CI (`.github/workflows/ci.yml`) يشغّل هذه الخطوات كلها؛ **أي تعديل يُضعف بوابة منها يتطلب commit مستقلاً موثَّقاً ببوابة مؤسس** (خطة §2.4).

## 2) متغيّرات البيئة

| المتغيّر | إلزامي؟ | ملاحظات |
|----------|---------|---------|
| `VITE_API_URL` (أو `VITE_API_BASE_URL`) | نعم | يفحصه `validateEnv()` عند الإقلاع |
| `VITE_APP_ENV` | لا | `development` / `staging` / `production` |
| `VITE_SENTRY_DSN` | لا | **بوابة لا تعطّل**: Sentry لا يُهيَّأ إلا بوجوده (chunk كسول، صفر كلفة بدونه) |

## 3) الخطوط (حسّاس — بوابة ترخيص)

- `public/fonts/*.woff2` (عائلات "Thmanyah"/"ThmanyahDisplay"): ارتكبها الفريق في دمج 2026-08 وتخدم الإنتاج.
- `public/fonts/thmanyah/` (OTF ثمانية الكاملة): **خارج git عمداً** (بوابة الترخيص رقم 1 في STATE) — لا تُزال من `.gitignore` ولا تُرتكب قبل نص الترخيص.
- سلاسل الخطوط في `tailwind.config.js` تجعل غياب أيٍّ من الطبقتين ينحدر بأمان إلى IBM Plex.

## 4) ترويسات الخادم

كتلة nginx الجاهزة (CSP تبدأ `Report-Only`) في `docs/03-changes/M4.5-security.md` §4 — تُطبَّق على مستوى الاستضافة، ليست جزءاً من `dist/`.

## 5) وصفة نشر يدوية (حتى أتمتة أعمق)

1. `git checkout dev && git pull` ثم تأكد أن CI أخضر على الـSHA المنشور.
2. `npm ci && npm run build` (مع env الإنتاج).
3. ارفع محتوى `dist/` إلى الاستضافة (استبدال ذرّي: مجلد جديد + تبديل symlink إن أمكن).
4. تحقّق بعد النشر: الصفحة الرئيسية + `/courses` + دخول لوحة دور واحد + `robots.txt`/`sitemap.xml`.
5. أي انحدار: أعد symlink إلى الإصدار السابق (احتفظ بآخر إصدارين على الخادم).

## 6) نقاط التنسيق مع الفريق (توصيات للتفعيل من مالك المستودع)

- **حماية فرع `dev` و`main`:** منع push مباشر، اشتراط CI أخضر، ومراجعة PR واحدة على الأقل.
- **Dependabot:** الإعداد في `.github/dependabot.yml` (أسبوعي، تجميع minor/patch) — التفعيل من Settings → Code security.
- **قاعدة الدمج المتبادل:** وظيفة الفريق تَغلِب؛ طبقة الهوية/الجودة تُعاد فوقها (خطة §2.1) — عند تعارض، لا تُسقطوا ميزة؛ أعيدوا تلوينها/تقنينها.
- **الحزم الجديدة:** تسجيل في STATE + `npm audit` قبل commit الإدخال (صفر ثغرات شرط الدمج).
- **الأرقام/الأسعار/الروابط العامة:** لا يُنشر غير المؤكَّد من المؤسس (STATE — بوابات مفتوحة).
- **النسخ الاحتياطي:** فروع `backup/pre-M<n>` لا تُحذف؛ bundle خارجي بعد كل مرحلة (بوابة 2).
