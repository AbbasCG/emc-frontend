## 1) خط الإنتاج (Build)

| خطوة | الأمر | الشرط |

## 3) الخطوط

- **طبقة واحدة فقط:** `public/fonts/*.woff2` (عائلات "Thmanyah"/"ThmanyahDisplay") — هي الوحيدة التي تُشحن، وسلاسل `tailwind.config.js` تنحدر منها بأمان إلى IBM Plex.
- `public/fonts/thmanyah/` (OTF الكاملة، 3.6MB): **خارج git** وغير مُشار إليها من أي CSS. الترخيص أُكّد (2026-08-07) لكنها **زائدة عن الحاجة** — الـwoff2 نفس المحارف وتغطي كل وزن مستعمل. إضافة plugin في `vite.config.ts` تحذفها من `dist/` كي يبقى البناء المحلي مطابقاً للمنشور.
  - ⚠️ **سابقة تُتجنَّب:** كانت عشر قواعد `@font-face` تشير إليها ⇒ **عشرة طلبات 404 في الإنتاج** عند كل تحميل، و3.6MB تدخل `dist` محلياً فتجعل كل قياس أداء غير ممثِّل. لا تُعِد إدخال أصول غير متتبَّعة في CSS.
- الوزن 300 (Light) **غير محمَّل عمداً**: `font-light` بلا أي استعمال.

## 4) ترويسات الخادم

كتلة nginx الجاهزة (CSP تبدأ `Report-Only`) في `docs/03-changes/M4.5-security.md` §4 — تُطبَّق على مستوى الاستضافة، ليست جزءاً من `dist/`.

## 5) وصفة نشر يدوية (حتى أتمتة أعمق)

1. `git checkout dev && git pull` ثم تأكد أن CI أخضر على الـSHA المنشور.
2. `npm ci && npm run build` (مع env الإنتاج).
3. ارفع محتوى `dist/` إلى الاستضافة (استبدال ذرّي: مجلد جديد + تبديل symlink إن أمكن).
4. تحقّق بعد النشر: الصفحة الرئيسية + `/courses` + دخول لوحة دور واحد + `robots.txt`/`sitemap.xml`.
5. أي انحدار: أعد symlink إلى الإصدار السابق (احتفظ بآخر إصدارين على الخادم).

## 6) نقاط التنسيق مع الفريق (توصيات للتفعيل من مالك المستودع)

- **حماية فرع `dev` و`main`:** منع push مباشر، اشتراط CI أخضر، ومراجعة PR واحدة على الأقل.
- **Dependabot:** الإعداد في `.github/dependabot.yml` (أسبوعي، تجميع minor/patch) — التفعيل من Settings → Code security.
- **قاعدة الدمج المتبادل:** وظيفة الفريق تَغلِب؛ طبقة الهوية/الجودة تُعاد فوقها (خطة §2.1) — عند تعارض، لا تُسقطوا ميزة؛ أعيدوا تلوينها/تقنينها.
- **الحزم الجديدة:** تسجيل في STATE + `npm audit` قبل commit الإدخال (صفر ثغرات شرط الدمج).
- **الأرقام/الأسعار/الروابط العامة:** لا يُنشر غير المؤكَّد من المؤسس (STATE — بوابات مفتوحة).
- **النسخ الاحتياطي:** فروع `backup/pre-M<n>` لا تُحذف؛ bundle خارجي بعد كل مرحلة (بوابة 2).

## 6b) prerender الصفحات العامة (اختياري — غير مُفعَّل افتراضياً)

`npm run build:prod` = `build` + `prerender`: يحمّل الـ24 مساراً العامّاً في Chromium (من Playwright، بلا حزمة جديدة) ويكتب DOM كل صفحة في `dist/<path>/index.html`. نداءات الـAPI مُلبّاة بحمولات فارغة حتى لا تُخبز حالة خطأ، واللغة مُثبَّتة على العربية، وكل صفحة **تُرفض** إن خرجت فارغة أو بلا `h1` أو بحالة خطأ أو بعنوان localhost — فتبقى CSR بدل شحن صفحة معطوبة. الرأس يأتي دائماً من قالب البناء (helmet يملك الـmeta وقت التشغيل).

⚠️ **مقيس: يخفض الأداء ولا يرفعه على هذا التطبيق** (perf 61→53 · LCP 6.5s→7.0s · CLS 0→0.155) — التفاصيل والسبب في [M9-perf-fonts-prerender.md](../03-changes/M9-perf-fonts-prerender.md). لذلك **`npm run build` الافتراضي لا يُشغّله**، ولا تستخدمه في النشر قبل معالجة سبب التدهور (`hydrateRoot`).

**لو فُعِّل يوماً:** يجب أن يخدم الخادم `/<path>/index.html` للمسار `/<path>` مع بقاء fallback إلى `/index.html` للمسارات غير المعروفة (وإلا انكسر التوجيه من طرف العميل).
