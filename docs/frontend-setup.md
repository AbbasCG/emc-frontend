# EMC Frontend — إعداد البيئة والنشر

دليل مختصر لتشغيل الواجهة الأمامية لمنصة EMC محلياً وربطها بالـ API.

## المتطلبات

- Node.js 20+ (يُنصح بأحدث إصدار LTS)
- npm

## التثبيت

```bash
npm install
```

## متغيرات البيئة

أنشئ ملف `.env` أو `.env.local` في جذر المشروع (بجانب `package.json`):

| المتغير | الوصف | مثال |
|---------|--------|------|
| `VITE_API_URL` | عنوان لوحة الـ API (يجب أن ينتهي غالباً بـ `/api` إذا كان الخادم يستخدم هذا البادئة) | `http://127.0.0.1:8000/api` |
| `VITE_API_BASE_URL` | بديل إذا لم يُعرّف `VITE_API_URL` | نفس القيمة أعلاه |

في الكود، يتم القراءة بالترتيب: `VITE_API_URL` ثم `VITE_API_BASE_URL` ثم الافتراضي `http://127.0.0.1:8000/api`.

## أوامر التشغيل

```bash
# خادم التطوير
npm run dev

# فحص lint
npm run lint

# بناء الإنتاج
npm run build

# معاينة بناء الإنتاج محلياً
npm run preview
```

بعد `npm run dev`، افتح الرابط الذي يعرضه Vite (عادة `http://localhost:5173`).

## الربط مع Laravel / Sanctum

- الواجهة ترسل `Authorization: Bearer <token>` المخزّن في `localStorage` (المفتاح `emc_token`).
- تأكد أن الخادم يقبل طلبات الـ SPA من أصل التطوير (مثلاً `http://localhost:5173`):
  - إعدادات **CORS** في Laravel (`config/cors.php`).
  - عند استخدام **Sanctum** مع SPA، راجع توثيق Laravel لـ `SANCTUM_STATEFUL_DOMAINS` و`SESSION_DOMAIN` إذا كانت الجلسات مطلوبة لمسارات معيّنة.
- استجابات الأخطاء الشائعة تُعرَض للمستخدم بالعربية عبر اعتراض Axios (`401`, `403`, `404`, `422`, `429`, `5xx`).

## الدفع التجريبي محلياً

توجد مسارات مثل `/fake-payment/:paymentId` للاختبار دون بوابة دفع حقيقية — راجع منطق الصفحة في `src/pages/FakePayment.tsx` ومسارات التسجيل في التطبيق.

## النشر (Production)

1. عرّف `VITE_API_URL` على عنوان الـ API الفعلي (HTTPS في الإنتاج).
2. نفّذ `npm run build`.
3. انشر مجلد `dist/` على أي استضافة ثابتة (أو خلف reverse proxy يوجّه `/api` إلى Laravel).

## صفحات الأخطاء

| المسار | الغرض |
|--------|--------|
| `/404` | صفحة غير موجودة (يمكن التوجيه إليها صراحةً) |
| `/403` | عدم وجود صلاحية |
| `/401` | مطلوب تسجيل الدخول |
| `/500` | خطأ خادم / صيانة |

مسار الالتقاط `*` يظل يعرض صفحة 404 داخل تخطيط الموقع العام.
