## 1) ما نُفِّذ

### A — تغطية PublicSeo: 8 → **32 صفحة (100%)**
- 21 صفحة عامة كانت بلا meta أصبحت تحمل `<PublicSeo/>` بعناوين وأوصاف عربية حقيقية مشتقة من محتوى كل صفحة نفسها (4 وكلاء بملكية حصرية — **صفر أرقام أو ادعاءات مخترعة**).
- صفحات الأدوات (شكراً/استعادة كلمة المرور/الأخطاء 401-403-404-500/نجاح طلب السفير) تحمل `noIndex` مع بقاء الـmeta نظيفة.
- تفاصيل الدورة: فروع التحميل/الخطأ/غير-موجودة كانت بلا meta إطلاقاً (وثيقة ما-قبل-البيانات في CSR) → fallback يعلوه الـmeta الحقيقي عند وصول البيانات، وفرع «غير موجودة» noIndex.

### B — بطاقة OG بهوية V3
`public/brand/og-default.png` (1200×630): فجر V3 + الشعار الأبيض الرسمي (بلا أي تعديل عليه) + الشريط الثلاثي — مولَّدة حتمياً بـ`scripts/generate-og-image.mjs` (sharp). صارت افتراضي `og:image` في PublicSeo بدل favicon.svg.

### C — sitemap + robots
`scripts/generate-sitemap.mjs` يولّد `public/sitemap.xml` (**24 مساراً قابلاً للفهرسة**) و`public/robots.txt` (يحجب `/dashboard` وصفحات الاستعادة، يشير إلى الـsitemap) من قائمة مسارات قانونية واحدة `scripts/public-routes.mjs`. الأمر: `npm run seo:assets`. المسارات الديناميكية (`:slug`) خارج الـsitemap عمداً — تحتاج تمريرة بيانات وقت البناء (ترتبط ببوابة prerender رقم 10).

### D — بيانات منظَّمة (مؤكَّد فقط)
- `EducationalOrganization` على الرئيسية: الاسم، الشعار، البريد، أمستردام/NL، حسابات السوشيال المنشورة أصلاً في التذييل. **بلا أي أرقام.**
- `Course` على تفاصيل الدورة: الاسم/الوصف/المزوِّد/الرابط من بيانات الـAPI الحية فقط — **لا تقييمات ولا أعداد ولا أسعار مُختلَقة.**

### E — البوابة الآلية
`src/test/publicSeoCoverage.test.ts` (**34 تأكيداً** ضمن 1099): يفشل البناء إذا فقدت أي صفحة قانونية `PublicSeo`، أو فقدت صفحة أدوات `noIndex`، أو انحرف الـsitemap الملتزَم عن قائمة المسارات.
