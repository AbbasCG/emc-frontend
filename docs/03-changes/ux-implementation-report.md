- ✅ خطّاف `useFocusTrap` (حصر تركيز + Escape + استعادة) مُطبَّق على النوافذ المشتركة (CrudModal/CrudDrawer/EntityDetailDrawer) + 8+ نوافذ مفردة.

## 🔜 البنود المتبقية — تحتاج قرارك أو اختباراً يدوياً (لم تُنفَّذ عمداً)

هذه البنود **متعمَّدة التأجيل** لأنها تتطلّب قراراً منتجيّاً أو اختباراً تشغيليّاً (e2e) لا يغطّيه البناء/الـlint:

| البند | لماذا يحتاجك | المرجع |
|-------|--------------|--------|
| **بنية تنقّل القائمة العلوية** (دمج المتشابهات، ≤5 عناصر) | قرار منتجيّ: أيّ المسارين القانونيّ — `/courses` أم `/programs`؟ ودمج «المركز»/«انضم إلينا» | nav worklist |
| **دمج خطوات المعالجات** (SubmitWorkshop 4→2، VolunteerApply 4→2) | إعادة هيكلة لوحات نموذج عاملة — تحتاج اختبار تدفّق فعليّ | flows worklist |
| **تأجيل الحقول الاختيارية** (city/gender بعد التسجيل في Signup/Enrollment) | يغيّر تدفّق التسجيل — يُفضَّل اختباره مع الخادم | flows worklist |
| **توحيد SectionHeader** (إعادة توجيه 26 ملفًّا + قرار شريط مصمت مقابل متدرّج) | تغيير بصريّ يحتاج مراجعة عين على 24 قسماً | section-header worklist |
| **اعتماد `emc-form-wizard`** في المعالِجَين العامّين | بعد دمج الخطوات | flows worklist |
| **بقية النوافذ المعقّدة** (CourseCmsFormModal، FormWizardShell، ConfirmDeleteModal→ConfirmDialog) | شِلّ متعدد الخطوات/تغيير سلوكيّ | modals worklist |
