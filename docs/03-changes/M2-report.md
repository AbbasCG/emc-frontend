# ✅ تقرير كتلة M2 — التبسيط الجذري (M2a → M2d)

> التاريخ: 2026-07-24 · القاعدة المرجعية: [route-map.md](../01-assessment/route-map.md) (جرد 342 مساراً) · كل مرحلة أُغلقت ببوابة خضراء كاملة: lint 0 · build · 259 وحدة · **28/28 E2E** (حاسوب + جوّال 375px).

## M2a — IA والتنقّل
- خريطة كاملة: 342 مساراً (70 redirects ~20%، 15 ملفاً يتيماً، 4 ComingSoon).
- **الحُكم:** `/courses` الكتالوج القانوني؛ `/programs` مكرَّر (نفس API نفس المكوّنات) → **أُخفي من القائمة فقط** (يبقى شغّالاً وفي التذييل) — قابل للتراجع بسطر.
- القائمة العلوية **6 → 4** + عنقود الدخول: البرامج (5 وجهات) · عن EMC (ابتلعت «المركز») · انضم إلينا (ابتلعت الشراكات + تقديم ورشة). مصادر الحقيقة الثلاثة (mega/prefixes/accordion الجوّال) حُدّثت معاً.
- الأشرطة الجانبية: نمط الطيّ الموحّد (الأولى مفتوحة، البقية مطوية) على super_admin/التنفيذي/المالية/الجودة/HR/مدير البرامج + إصلاح **عنصر مكرّر حرفياً**.

## M2b — توحيد المكوّنات + الصلابة
- **SectionHeader 4→1**: القانوني `ui/SectionHeading` (وُسّع إضافياً)؛ النسختان الأخريان أصبحتا adapters رفيعة — **26 مستورِداً بلا أي تعديل**. قوس العناوين ترقّى عالمياً إلى **القوس المزدوج V3** بتعديل CSS واحد.
- تدقيق App*: جدول استخدام كامل؛ AppCard/AppSelect **ميّتان** (حذف مؤجَّل ببوابة)؛ وسوم @deprecated حيث يوجد بديل.
- **تحصين الجلب:** `timeout: 20s` على apiClient + خطّاف `useFetch` (إجهاض، حماية من النتائج القديمة، لا setState بعد الفكّ) مُتبنّى في 4 مواقع عالية الأثر.
- **صلابة:** SectionErrorBoundary يلفّ عناقيد المسارات الكسولة (فشل chunk لا يُسقط التطبيق) + مفاتيح إخفاء `featureFlags.ts` (روابط ComingSoon مخفية من الشريط، المسارات تبقى).
- تواقيع V3 السطحية: الشريط الثلاثي (التذييل + الأبطال) · شارة الأوراق على حقول الفجر · النمط الذهبي على CTA الكبرى (≤2 توقيع/مشهد).

## M2c — التدفّقات
- **VolunteerApply: 4 → 2 خطوات** (المراجعة ذيل الخطوة الثانية) بعقد API مطابق بايتاً-ببايت + **سدّ ثغرة حقيقية**: قواعد الخطوة الثانية لم تكن تُفحص قبل الإرسال.
- المنجز سابقاً تحقّق عبر E2E (معالج الورشة بموعد واحد، auto-fill الدولة، التحقّق الفوري).
- enrollment/payment و city/gender: **بلا تغيير عمداً** — يتطلبان تنسيق قواعد Laravel (بوابة مفتوحة مسجَّلة).

## M2d — اللوحات
- جرد أنماط 8 لوحات أدوار + إصلاح كسّارات 375px الحقيقية: جدول خام بلا `overflow-x-auto` (لوحة القيادة)، صفوف رأس/مالية بلا التفاف، شبكات KPI 2-up على الجوّال (Admin/Teacher).
- الانحرافات البنيوية الكبرى (لغة «مركز الاستخبارات» في لوحة القيادة، أبطال مخصّصة) وُثّقت ولم تُعَد هيكلتها (قرار الحدّ الأدنى من التدخّل).

## أرقام الكتلة
| قبل M2 | بعد |
|--------|-----|
| قائمة 6 عناصر + مكرّرات | **4** + مسار قانوني واحد |
| 4 مكوّنات عنوان قسم | **1** قانوني + adapters |
| أشرطة ممدودة (~55 رابطاً مفتوحاً للأدمن) | طيّ موحّد عبر الأدوار |
| معالج تطوع 4 خطوات | **2** |
| جلب بلا timeout/إجهاض | 20s + useFetch |
| فشل chunk = شاشة بيضاء | تدهور موضعي بحدود أخطاء |
